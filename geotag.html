True EXIF metadata only exists in the JPEG/TIFF format. JPEG photos get the clinic's details, treatment, and GPS coordinates written directly into their existing EXIF block — the image data is not re-encoded, so quality is unchanged. PNG, WEBP, GIF, and BMP don't support this kind of metadata natively, so those are converted to JPEG first and the metadata is written into the new file; the badge on each photo tells you which happened. Everything runs entirely inside this browser tab.
